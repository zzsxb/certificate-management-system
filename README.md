# 郑州分行持证上岗证书管理系统需求书

**文档版本**：V1.0

**编制日期**：2025年XX月XX日

**适用范围**：郑州分行内部持证上岗证书全流程管理

**开发与运行要求**：基于Electron框架开发，适配Windows 10/11、国产麒麟操作系统；采用SQLite本地轻量数据库；支持多维度模糊查询、自动化数据联动计算、标准化模板导入导出；界面大气简洁，所有功能模块支持最大化操作。

## 一、项目背景

郑州分行每月组织一次持证上岗考试，每年开展一次证书继续教育工作，且每年会制定并更新持证上岗必考岗位清单，各岗位对应1个或多个必考证书。日常运营中存在人员入职、平调、离职等频繁变动场景，人工管理证书存在效率低、易出错、统计不及时、岗位-证书匹配偏差等问题。为解决上述痛点，需搭建一套本地化桌面管理系统，实现人员证书的系统化、自动化、精准化全生命周期管理，替代人工处理证书新增、岗位匹配、继续教育、统计分析等核心工作。

## 二、建设目标

1. 实现**人员-PS岗位-必考证书**的全链路联动管理，基于PS岗位自动匹配对应必考证书，人员变动时自动重新计算应考证书，大幅减少人工操作与人为误差。

2. 支持月度证书新增、年度继续教育结果批量导入，自动化处理证书有效/失效状态，失效证书自动从已持证书中移除，同时永久保留证书与继续教育历史记录。

3. 提供标准化Excel模板下载与批量导入功能，上传模板后系统自动刷新页面、全量重新计算关联数据，无需手动触发刷新。

4. 实现多维度模糊查询（OA号、姓名、PS岗位、证书名称），以及实时统计分析，支持一键展示所有应考未考人员详情，提升数据查询与统计效率。

5. 搭建大气简洁、符合银行办公习惯的可视化界面，支持双击查看人员全量详情、双击展开统计明细表格，所有界面均提供最大化按钮，适配日常办公操作场景。

6. 实现本地加密数据存储，保障内部数据安全性，同时实现Windows、麒麟系统跨平台兼容，无需额外插件即可一键安装运行。

## 三、核心定义与计算规则

### 3.1 核心定义

1. **唯一识别规则**：以**OA号**作为人员唯一识别码，解决同名不同人问题，系统内所有数据关联、匹配、更新均基于OA号执行。

2. **PS岗位规则**：PS岗位为银行内部特定岗位术语，是匹配必考证书的唯一核心依据，所有岗位-证书关联、必考证书计算、人员变动联动均基于PS岗位执行。

3. **证书状态规则**：证书仅分为**有效、失效**两种状态；有效证书计入员工“已持证书”，参与应考未考计算；继续教育不通过的证书标记为失效，从已持证书中直接移除，仅保留历史记录，不参与任何业务计算。

4. **继续教育规则**：继续教育周期为自然年，系统永久记录每年各证书的继续教育结果，形成可追溯的继续教育历史台账。

5. **人员状态规则**：人员分为**在职、离职**两种状态；离职人员信息全行标红并备注“离职”，不参与后续必考证书计算、应考未考统计等所有业务操作。

### 3.2 核心自动计算公式

1. 个人必考证书 = 当前PS岗位对应的所有必考证书（取自PS必考岗位对照表）

2. 个人应考未考证书 = 必考证书 - 已持有效证书

3. 通过人次 = 已持有效证书完全覆盖所有必考证书的在职人员数量

4. 应考未考人次 = 存在至少1项必考证书未获取的在职人员数量

## 四、核心业务功能需求

### 4.1 人员信息全生命周期管理模块

#### 4.1.1 人员变动批量处理（入职/平调/离职）

1. **入职处理**：导入标准化人员调整模板后，系统自动新增人员基础信息（OA号、姓名、PS岗位），并根据《PS必考岗位对照表》自动匹配该岗位对应的所有必考证书，同步生成该人员的“应考未考证书”列表。

2. **平调处理**：导入标准化人员调整模板后，系统**永久保留该人员原有有效已持证书**，根据新PS岗位重新匹配对应必考证书，自动全量重新计算应考未考证书列表，同时记录调岗历史（原PS岗位、新PS岗位、调岗时间、操作备注）。

3. **离职处理**：导入标准化人员调整模板后，系统将该人员全量信息标红显示，在备注栏自动标注“离职”，同时将该人员从在职人员统计池中剔除，不参与后续所有业务计算与统计。

4. 所有人员变动操作均生成可追溯的变动台账，可在人员详情页全量查看。

#### 4.1.2 人员查询与检索

1. 支持**OA号、姓名**的模糊查询，输入关键词后实时过滤人员列表，快速定位目标人员，查询结果响应时间≤1秒。

2. 支持查询结果的表格化展示，展示字段与主界面核心表格完全一致，支持最大化全屏查看、Excel格式导出。

### 4.2 证书全流程管理模块

#### 4.2.1 月度证书新增管理

1. 导入标准化证书新增模板后，系统根据OA号自动匹配人员信息，按以下规则执行：

    - 若该人员已在系统内存在，直接为其新增对应证书，标记为**有效**，计入“已持证书”，并自动更新该人员的应考未考证书列表（若该证书为必考证书，自动从应考未考列表中剔除）；

    - 若该人员未在系统内存在，系统自动新增人员基础信息（OA号、姓名），再添加对应证书，PS岗位支持后续手动补充。

2. 证书新增时同步记录证书获取时间，所有证书明细可在人员详情页查看。

3. 同一OA号+同一证书名称，系统仅保留1条有效记录，避免重复录入。

#### 4.2.2 年度继续教育管理

1. 导入标准化继续教育模板后，系统根据OA号+证书名称精准匹配对应记录，按继续教育结果自动执行以下操作：

    - **结果为通过**：不修改证书原有有效状态，仅在继续教育历史台账中新增记录（OA号、姓名、证书名称、继续教育年份、结果、操作时间）；

    - **结果为不通过**：将对应证书标记为**失效**，从该人员的“已持证书”中直接移除，同时在继续教育历史台账中新增记录，并自动重新计算该人员的应考未考证书列表（若该证书为必考证书，自动重新加入应考未考列表）。

2. 继续教育历史永久留存，支持在人员详情页按年份筛选查看。

#### 4.2.3 证书状态管理

1. 证书状态仅支持系统自动更新，不支持手动修改/删除，仅可通过“继续教育不通过”实现证书失效，保障数据可追溯性。

2. 失效证书仅在人员详情页的“失效证书历史”模块展示，不展示在主界面“已持证书”列，不参与任何业务计算。

### 4.3 PS岗位-必考证书关联管理模块

#### 4.3.1 必考岗位清单维护

1. 支持PS岗位、对应必考证书的**新增、修改、删除、批量编辑**操作，所有操作实时保存至数据库，界面操作简洁直观。

2. 必考岗位清单发生任何变更后，系统**自动联动全量在职人员**，重新匹配各人员的必考证书，并全量更新应考未考证书列表，无需手动触发计算。

3. 岗位清单以表格化展示，固定表头为「PS岗位、必考证书」，与现有《PS必考岗位对照表》格式完全一致，支持表格导出为Excel格式。

#### 4.3.2 岗位/证书快速查询

1. 支持**PS岗位名称、证书名称**的模糊查询，输入关键词后实时过滤岗位清单，快速定位目标岗位与证书的对应关系。

2. 查询结果支持最大化全屏查看、Excel格式导出。

### 4.4 统计分析与数据展示模块

#### 4.4.1 实时核心指标统计

系统实时计算并在主界面显著位置展示2项核心统计指标：**通过人次、应考未考人次**，数据随人员变动、证书新增、继续教育导入、岗位清单变更实时更新。

#### 4.4.2 统计结果交互

1. 核心统计指标（通过人次、应考未考人次）**双击可展开详细表格**，展示对应人员的完整信息，表格字段与主界面核心表格一致，支持模糊查询、最大化全屏查看、Excel导出。

2. 主界面固定设置**应考未考人员详情**一键查询按钮，点击后直接跳转展示所有应考未考人员的完整信息，支持模糊查询、最大化全屏查看、Excel导出。

#### 4.4.3 主界面核心数据表格

主界面核心区域以固定表格展示所有在职人员的核心数据，固定表头不可修改，具体列如下：

|固定列名|展示规则|
|---|---|
|OA号|人员唯一识别码，不可修改|
|姓名|人员姓名，与OA号绑定|
|PS岗位|人员当前在职岗位，为匹配必考证书的核心依据|
|已持证书|人员当前所有有效证书，多个证书以“，”分隔|
|必考证书|人员当前PS岗位对应的所有必考证书，多个证书以“，”分隔|
|应考未考证书|人员当前未获取的必考证书，多个证书以“，”分隔|
|是否有应考未考|仅展示“是/否”，“是”的行高亮提示|
|备注|记录离职、岗位待补充等信息，支持手动编辑|
### 4.5 标准化模板管理模块

#### 4.5.1 固定模板下载

系统主界面顶部固定设置**模板下载**专区，永久提供3类标准化Excel模板的下载入口，模板格式不可修改，字段均标注必填/选填属性与填写说明，具体模板详见附件。

#### 4.5.2 模板导入与校验

1. 支持上述3类模板的Excel文件批量导入，导入时系统自动执行全量校验，若存在必填字段空值、格式错误、OA号不存在等问题，弹窗提示**具体错误行号+错误原因**，本次导入不生效；校验全部通过后，方可执行导入操作。

2. 模板导入成功后，系统**自动刷新主界面所有数据**，全量重新计算统计指标、必考证书、应考未考证书列表，无需手动刷新页面。

### 4.6 人员详情查看功能

1. 主界面核心表格中，**双击任意人员行**，弹出美化后的人员详情独立窗口，界面采用卡片式布局，大气直观、信息层级清晰，支持最大化全屏查看。

2. 详情页固定分为4个模块，全量展示该人员的所有信息：

    - 基础信息模块：OA号、姓名、PS岗位、人员状态、备注、入职时间；

    - 证书明细模块：分为「已持有效证书」「失效证书历史」两个子项，展示证书名称、获取时间、失效时间；

    - 继续教育历史模块：按年份倒序展示，包含证书名称、继续教育年份、结果、操作时间；

    - 人员变动历史模块：按时间倒序展示，包含变动类型、原PS岗位、新PS岗位、变动时间、备注。

## 五、界面与交互需求

1. **整体视觉风格**：采用大气、简洁、专业的银行办公系统风格，主色调为浅蓝+白色，避免冗余装饰元素，信息层级清晰，重点内容突出。

2. **最大化功能**：所有独立界面（主界面、统计详情页、岗位清单管理页、人员详情页、查询结果页）均在右上角固定设置**最大化按钮**，支持全屏查看，适配不同尺寸的办公显示器。

3. **操作便捷性**：核心功能（模板下载、模板导入、应考未考详情、岗位清单管理）均在主界面设置固定快捷按钮，无需多级菜单查找，减少操作路径。

4. **自动刷新机制**：所有模板导入、岗位清单变更操作完成后，系统自动刷新主界面、统计指标、所有关联数据，无手动刷新按钮，避免数据不同步。

5. **表格交互优化**：所有表格支持列宽拖动、内容自动换行、单列排序、鼠标滚轮翻页，2000+条大数据量加载时间≤3秒，无卡顿。

6. **操作反馈机制**：所有操作（导入、新增、修改、删除）均提供明确的成功/失败弹窗提示，失败提示需包含具体可落地的原因，无模糊反馈。

7. **高亮提示规则**：离职人员全行标红、有应考未考的人员行高亮、失效证书灰色标注，视觉区分清晰。

## 六、技术与适配要求

1. **开发框架**：采用Electron框架开发，实现Windows 10/11、国产麒麟操作系统的跨平台兼容，系统提供一键安装包，无需依赖其他插件、运行环境即可安装运行。

2. **数据库**：采用SQLite本地轻量数据库，所有数据加密存储在本地，保障内部数据安全性，同时支持数据库文件手动备份与恢复功能。

3. **文件兼容**：模板下载/导入、表格导出均采用Excel（.xlsx/.xls）格式，兼容微软Office、金山WPS等主流办公软件。

4. **性能要求**：

    - 模糊查询响应时间≤1秒，输入关键词后实时过滤结果；

    - 全量2000+人员数据重新计算时间≤3秒，无卡顿；

    - 系统启动时间≤5秒，无长时间加载等待。

5. **兼容性要求**：在Windows、麒麟系统上，界面显示无乱码、无布局错乱、无按钮失效等问题，所有功能均可正常运行。

6. **数据安全要求**：支持本地数据一键备份、手动恢复，数据库文件加密存储，防止非授权访问与数据泄露。

### 7.4 可扩展性

1. 支持后续新增证书类型、PS岗位，无需修改系统核心代码。

2. 支持后续新增统计指标、数据导出格式，预留功能扩展接口。
